# E-Commerce Web Site (Shopping Cart)

A simple front-end shopping page where products are listed, items can be added to a cart, and the cart total is shown.

**Live demo:** [https://narendra2222.github.io/Ecommers_web_site/](https://narendra2222.github.io/Ecommers_web_site/)

---

## Features

- Product listing ("Shopping Product" section)
- Cart section showing the items added ("cart items")
- Running order total, starting at `$0.00` ("Total")
- Responsive layout (the page uses the viewport meta tag for mobile screens)

> Add more here as you build them, for example: remove item, quantity buttons, search, checkout.

## Technologies Used

- HTML5: page structure
- CSS3: styling and layout
- JavaScript: cart logic and updating the total
- GitHub Pages: hosting

## How to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/narendra2222/Ecommers_web_site.git
   ```
2. Open the folder:

   ```bash
   cd Ecommers_web_site
   ```
3. Open `index.html` in any web browser. No installation or build step is needed.

## How It Works

1. Products are displayed in the **Shopping Product** section.
2. When a product is added, it appears under **cart items**.
3. The **Total** is recalculated and shown at the bottom of the cart.
